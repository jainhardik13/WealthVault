# BSE Stock Codes Reference
================================

This file contains commonly used BSE stock codes for popular Indian companies.
BSE uses numeric codes instead of ticker symbols like NSE.

## How to Use BSE Stocks in WealthVault:
1. Select "BSE (Bombay Stock Exchange)" from the Exchange dropdown
2. Enter the BSE stock code (numeric) in the Symbol field
3. Example: For TCS, use "532540" instead of "TCS"

## Finding BSE Codes:
If you need to find a BSE code not listed here:
1. Visit: https://www.bseindia.com/
2. Search for the company name
3. The BSE code (Scrip Code) will be displayed in the stock details

## Note:
- BSE codes are numeric (6 digits)
- NSE uses alphabetic symbols (e.g., TCS, RELIANCE)
- Make sure to select the correct exchange when adding stocks
- Historical charts currently only support NSE stocks
